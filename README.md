# Bludit Video Upload Plugin

Ein Plugin für [Bludit CMS](https://www.bludit.com), mit dem sich kurze Video-Clips
(MP4, WebM, MOV) hochladen und als klickbare Kachel im Frontend anzeigen lassen.
Die Kachel verlinkt direkt auf eine gewählte Kategorie oder Seite – ein separater
Video-Player ist nicht nötig.

## Funktionen

- Hochladen kurzer Videoclips über das Bludit-Backend
- Anzeige als klickbare Vorschau-Kachel im Frontend
- Ziel-Link pro Video frei wählbar (Kategorie oder Seite)
- Einstellbare Rubrik-Schlüssel für die Vorschau-Auswahl

## Installation

1. Dieses Repository als ZIP herunterladen
2. Den Ordner-Inhalt nach `bl-plugins/video-upload/` in die Bludit-Installation kopieren
3. Im Bludit-Backend unter **Plugins** das Plugin **"Video-Upload"** aktivieren
4. Einstellungen bei Bedarf unter **Plugins → Video-Upload → Einstellungen** anpassen
